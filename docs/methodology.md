# Methodology

This repository treats risk and resilience as systems concepts rather than narrow management terms.

The workflow uses structured metadata for:

- risk and resilience concepts
- hazard categories
- exposure and vulnerability relationships
- system dependencies
- resilience indicators
- scenario matrices
- article planning
- source hierarchy

The method combines systems thinking, disaster-risk research, climate adaptation, social-ecological systems theory, infrastructure resilience, risk governance, indicator review, scenario planning, and critical analysis of vulnerability and justice.
