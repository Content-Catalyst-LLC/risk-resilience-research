# Resilience Measurement Notes

Resilience indicators should not be treated as definitive measures of system capacity.

Use indicators to support analysis, but document:

- what system is being measured
- the scale of analysis
- the time horizon
- whether the indicator measures hazard, exposure, vulnerability, sensitivity, adaptive capacity, response capacity, recovery, transformation, or justice
- data limitations
- missing social or ecological context
- whether risk is displaced onto other groups or systems
