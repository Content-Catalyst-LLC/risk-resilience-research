# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| hazard_probability | Estimated likelihood or normalized probability of the primary hazard | 0–1 |
| expected_loss_index | Normalized severity or consequence estimate | 0–1 |
| probability_uncertainty | Uncertainty in the probability estimate | 0–1 |
| loss_uncertainty | Uncertainty in the loss estimate | 0–1 |
| dependency_density | Degree of interdependence across system components | 0–1 |
| feedback_strength | Strength of reinforcing or balancing feedback dynamics | 0–1 |
| threshold_sensitivity | Susceptibility to nonlinear change or regime shift | 0–1 |
| adaptive_behavior | Degree to which actors or components change system behavior over time | 0–1 |
| monitoring_capacity | Ability to observe, detect, and validate changing conditions | 0–1 |
| redundancy_capacity | Spare, backup, distributed, or substitute capacity | 0–1 |
| flexibility_capacity | Ability to switch pathways, modify operations, or adapt strategy | 0–1 |
| institutional_learning | Ability to learn from signals, failures, and new information | 0–1 |
| adaptive_governance_capacity | Ability to revise policy, coordinate response, and govern under uncertainty | 0–1 |
| social_vulnerability | Susceptibility of exposed populations to harm | 0–1 |
| criticality_index | Importance of the system for wider service continuity | 0–1 |
