## Purpose

This folder provides reproducible scaffolding for modeling critical infrastructure resilience and interdependent systems as relationships among:

- infrastructure criticality
- hazard exposure
- asset fragility
- cyber-physical risk
- redundancy
- maintenance capacity
- governance capacity
- recovery capacity
- backup capacity
- workforce readiness
- service demand under stress
- social vulnerability
- dependency matrices
- direct failure pressure
- interdependence exposure
- resilience capacity
- cascading infrastructure risk
- service-continuity gaps
- recovery-priority scoring
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced interdependence, cascading-risk, and service-continuity diagnostics
- R: dashboard-ready infrastructure resilience, sector, regional, and scenario summaries
- SQL: schema scaffold for infrastructure systems, dependency records, outages, maintenance, cyber incidents, service continuity, and source provenance
- Go: lightweight infrastructure resilience scoring service scaffold
- Rust: command-line resilience-capacity scoring utility
- C: compact direct failure-pressure calculation
- C++: cascading-risk and recovery-priority example
- Fortran: numerical service-continuity gap example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
