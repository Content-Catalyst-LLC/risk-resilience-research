# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| dependency_density | Degree of dependence among system components | 0–1 |
| hidden_coupling | Degree of operational coupling that is not obvious from formal diagrams | 0–1 |
| feedback_delay | Delay between cause, signal, response, and visible consequence | 0–1 |
| signal_visibility | Ability to detect weak signals and deterioration before breakdown | 0–1 |
| buffer_capacity | Slack, reserves, ecological buffers, inventory, and spare capacity | 0–1 |
| redundancy_capacity | Backup, substitution, duplication, and alternative service pathways | 0–1 |
| modularity_capacity | Ability to isolate failures and prevent system-wide spread | 0–1 |
| adaptation_debt | Accumulated hidden fragility from workarounds and normalized strain | 0–1 |
| optimization_pressure | Pressure toward lean, centralized, tightly coupled efficiency | 0–1 |
| maintenance_deficit | Deferred maintenance, underinvestment, or degraded physical/institutional condition | 0–1 |
| monitoring_capacity | Ability to observe system state, validate signals, and trigger response | 0–1 |
| governance_coordination | Ability to coordinate across sectors, scales, and institutions | 0–1 |
| social_vulnerability | Susceptibility of exposed populations to harm | 0–1 |
| system_criticality | Importance of the system for essential services and cascading consequences | 0–1 |
| external_stress | External hazard or disruption pressure applied to the system | 0–1 |
