**Why Complex Systems Fail**

## Purpose

This folder provides reproducible scaffolding for modeling complex system failure as an emergent result of:

- interdependence
- hidden coupling
- delayed feedback
- buffer erosion
- loss of slack
- adaptation debt
- optimization pressure
- monitoring gaps
- degraded redundancy
- modularity weakness
- governance coordination limits
- cascading failure potential
- social vulnerability
- critical-service dependence
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced diagnostics, scenario analysis, and Monte Carlo uncertainty
- R: dashboard-ready failure-risk, coupling, cascade, and resilience summaries
- SQL: schema scaffold for systems, indicators, scenarios, and scoring runs
- Go: lightweight scoring service scaffold
- Rust: command-line failure-risk scoring utility
- C: compact coupling-risk calculation
- C++: cascade potential example
- Fortran: numerical failure-gap example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
