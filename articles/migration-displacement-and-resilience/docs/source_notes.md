# Source Notes

Suggested source families for production use:

- IOM fundamentals of migration, key migration terms, and migration data portal resources
- UNHCR Global Trends and Figures at a Glance
- IDMC Global Report on Internal Displacement
- World Bank Groundswell reports and forced-displacement materials
- IPCC AR6 WGII climate risk, adaptation, vulnerability, and human mobility materials
- National statistics, displacement tracking, migration surveys, remittance records, service-capacity data, and host-community data
- Climate hazard, conflict-event, livelihood, water, food, public health, social vulnerability, and protection-access datasets

This sample package uses synthetic data only.
