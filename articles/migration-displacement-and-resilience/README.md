# Migration, Displacement, and Resilience

This article folder supports the Risk & Resilience knowledge-series article:

**Migration, Displacement, and Resilience**

Article URL:
https://sustainablecatalyst.com/migration-displacement-and-resilience/

Repository folder:
https://github.com/Content-Catalyst-LLC/risk-resilience-research/tree/main/articles/migration-displacement-and-resilience

## Purpose

This folder provides reproducible scaffolding for modeling migration, displacement, and resilience as relationships among:

- hazard pressure
- livelihood stress
- conflict and insecurity pressure
- exposure
- social vulnerability
- adaptive capacity
- mobility resources
- protection access
- migration network strength
- destination service capacity
- host-community support
- recovery capacity
- arrival pressure
- mobility pressure
- adaptive mobility capacity
- forced-displacement risk
- trapped-population risk
- destination stress
- mobility resilience gaps
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced mobility, displacement, and resilience diagnostics
- R: dashboard-ready migration, displacement, regional, context, and scenario summaries
- SQL: schema scaffold for places, mobility indicators, displacement events, host-community services, protection pathways, and source provenance
- Go: lightweight migration-displacement resilience scoring service scaffold
- Rust: command-line adaptive mobility capacity scoring utility
- C: compact forced-displacement risk calculation
- C++: trapped-population and mobility-resilience gap example
- Fortran: numerical mobility-resilience gap example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
