# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| disruption_severity | Normalized severity of shock or ongoing stress | 0–1 |
| recovery_capacity | Ability to restore essential function after disruption | 0–1 |
| recovery_speed | Relative speed of functional restoration | 0–1 |
| essential_function_restoration | Degree to which life-supporting or critical functions can be restored | 0–1 |
| adaptive_capacity | Ability to adjust practices, systems, and institutions to changing conditions | 0–1 |
| governance_capacity | Ability to coordinate, plan, finance, regulate, and implement response pathways | 0–1 |
| learning_capacity | Ability to learn from signals, failures, monitoring, and changing conditions | 0–1 |
| ecological_buffer_capacity | Ecosystem-based capacity to reduce stress and support adaptation | 0–1 |
| social_protection_capacity | Safety nets, health access, income support, and protection during transition | 0–1 |
| transformation_readiness | Institutional, social, technical, and political readiness for deeper structural change | 0–1 |
| structural_unsustainability | Degree to which existing arrangements are no longer viable, just, or ecologically sound | 0–1 |
| justice_pressure | Degree to which unequal harm, exclusion, or legitimacy deficits require deeper change | 0–1 |
| maladaptation_risk | Risk that adaptation reduces short-term harm while increasing long-term or displaced risk | 0–1 |
| residual_risk | Remaining risk after recovery and adaptation efforts | 0–1 |
| public_legitimacy | Trust, participation, and legitimacy supporting response pathways | 0–1 |
