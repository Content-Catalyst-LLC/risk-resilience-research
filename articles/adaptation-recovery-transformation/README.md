## Purpose

This folder provides reproducible scaffolding for modeling three response pathways in sustainable systems:

- recovery: restoration of essential function after disruption
- adaptation: adjustment to changing conditions and future risk
- transformation: deeper structural change when existing arrangements become untenable
- recovery capacity
- adaptation capacity
- transformation readiness
- residual risk
- maladaptation risk
- justice safeguards
- climate-resilient development pathways
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced diagnostics, scenario analysis, and Monte Carlo uncertainty
- R: dashboard-ready recovery, adaptation, transformation, and pathway summaries
- SQL: schema scaffold for systems, indicators, scenarios, and scoring runs
- Go: lightweight scoring service scaffold
- Rust: command-line response-pathway scoring utility
- C: compact recovery gap calculation
- C++: adaptation capacity example
- Fortran: numerical transformation readiness example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
