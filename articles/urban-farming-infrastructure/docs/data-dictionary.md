# Data Dictionary

The file `data/raw/urban_farming_resilience_synthetic.csv` contains synthetic demonstration data for urban farming infrastructure and food-system resilience analysis.

| Field | Description |
|---|---|
| node_id | Synthetic urban farming infrastructure node identifier |
| city | Synthetic city name |
| neighborhood | Synthetic neighborhood or district |
| production_type | Type of urban farming infrastructure |
| crop_category | Broad crop category |
| annual_output_kg | Annual production output in kilograms |
| served_households | Approximate households served by the node |
| essential_demand_kg | Annual essential demand estimate for the relevant food category |
| water_liters_per_kg | Water intensity estimate |
| energy_kwh_per_kg | Energy intensity estimate |
| land_area_m2 | Cultivated or facility area in square meters |
| food_access_priority | Relative food-access priority of the neighborhood |
| local_distribution_share | Share of output distributed locally |
| waste_recapture_kg | Annual organic waste or nutrient recovery contribution |
| shock_external_supply_loss_fraction | Synthetic external supply-loss scenario |
