# Ethics and Scope Note

Urban farming infrastructure affects land, food access, neighborhood stability, public health, labor, environmental exposure, and community control.

Applied analysis should avoid treating food insecurity as a purely technical problem. It should account for poverty, housing costs, transportation, racialized disinvestment, land tenure, displacement risk, culturally appropriate food, worker dignity, and community-led governance.

This scaffold uses synthetic data for educational purposes. It is not a substitute for community participation, food-justice analysis, public-health review, local agricultural expertise, or accountable urban planning.
