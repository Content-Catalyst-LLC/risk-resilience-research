# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| ecosystem_condition | Overall health and functionality of the ecosystem used in the solution | 0–1 |
| biodiversity_benefit | Degree to which the project protects or improves biodiversity and functional diversity | 0–1 |
| ecological_connectivity | Habitat, watershed, corridor, or landscape connectivity supported by the project | 0–1 |
| intervention_quality | Technical and ecological suitability of the project design | 0–1 |
| governance_capacity | Institutional ability to coordinate, regulate, monitor, and protect the project | 0–1 |
| maintenance_capacity | Long-term stewardship, funding, monitoring, and repair capacity | 0–1 |
| hazard_pressure | Climate, flood, heat, erosion, drought, storm, landslide, or water-risk pressure | 0–1 |
| exposure | People, assets, infrastructure, ecosystems, and services in harm's way | 0–1 |
| social_vulnerability | Unequal susceptibility and limited capacity to avoid or recover from harm | 0–1 |
| social_legitimacy | Community participation, rights protection, trust, and public legitimacy | 0–1 |
| livelihood_benefit | Degree to which the project supports livelihoods, access, wellbeing, or local benefit | 0–1 |
| displacement_pressure | Risk of displacement, exclusion, green gentrification, or livelihood restriction | 0–1 |
