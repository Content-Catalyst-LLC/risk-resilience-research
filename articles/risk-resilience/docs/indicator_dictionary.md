# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| hazard_pressure | Severity or probability-weighted pressure from hazards | 0–1 |
| exposure | Presence of people, assets, ecosystems, institutions, or infrastructures in harm’s way | 0–1 |
| vulnerability | Susceptibility to harm, disruption, or loss | 0–1 |
| protective_capacity | Preparedness, response capacity, infrastructure protection, and adaptive resources | 0–1 |
| robustness | Ability to withstand stress without severe loss of function | 0–1 |
| redundancy | Spare, backup, distributed, or substitute capacity | 0–1 |
| adaptive_capacity | Ability to learn, adjust, and reorganize | 0–1 |
| recovery_capacity | Ability to restore essential function after disruption | 0–1 |
| transformation_capacity | Ability to change systems that are no longer viable, just, or sustainable | 0–1 |
| justice_legitimacy | Fairness, participation, trust, and protection for vulnerable groups | 0–1 |
| functional_loss_area | Approximate cumulative functional loss during recovery | positive numeric |
