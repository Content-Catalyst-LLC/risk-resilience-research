# Coastal Flood Risk and Baseline Assumptions

This folder contains reproducible companion materials for the article **Coastal Flood Risk and Baseline Assumptions**.

The scaffold examines how baseline sea-level assumptions can change coastal flood-exposure estimates. It uses synthetic data to demonstrate threshold-based exposure modeling, baseline-correction sensitivity, infrastructure exposure, and population-at-risk calculations.

## Article focus

Coastal flood risk is often described as a future consequence of sea-level rise, but present-day exposure can also be underestimated when baseline sea-level assumptions are inaccurate or when vertical datums, land elevation, tide gauges, satellite altimetry, storm surge, and local subsidence are not integrated consistently.

## What this scaffold includes

- Synthetic coastal asset and population data.
- Baseline sea-level correction examples.
- Threshold exposure models.
- Python and R workflows.
- SQL schema and analytical views.
- Julia, C, C++, Fortran, Go, and Rust examples for simple exposure-threshold logic.
- Documentation for validation, ethics, and methodological scope.
- A WordPress-ready GitHub embed block.

## Responsible use

This scaffold uses synthetic data and simplified assumptions. It is intended for public-interest learning, reproducible analysis, climate-risk literacy, and transparent methodological demonstration.

It should not be used as the sole basis for official flood mapping, insurance pricing, zoning, public infrastructure siting, relocation policy, emergency management, environmental permitting, or financial risk decisions without expert review, local data validation, community participation, and institutional accountability.
