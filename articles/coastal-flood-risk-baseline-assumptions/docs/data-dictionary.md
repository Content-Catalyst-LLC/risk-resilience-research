# Data Dictionary

The file `data/raw/coastal_assets_synthetic.csv` contains synthetic demonstration data for coastal flood-exposure analysis.

| Field | Description |
|---|---|
| site_id | Synthetic site identifier |
| region | Synthetic coastal region |
| asset_type | Asset, facility, or exposed system type |
| population | Population associated with the site |
| asset_value_musd | Synthetic asset value in millions of U.S. dollars |
| land_elevation_m | Local land elevation in meters |
| protection_height_m | Protective elevation provided by built defenses or site improvements |
| modeled_baseline_m | Modeled baseline sea-level reference |
| baseline_correction_m | Local correction added to the modeled baseline |
| sea_level_rise_scenario_m | Scenario increment for future sea-level rise |
| tide_surge_m | Combined tide and storm-surge contribution |
| uncertainty_margin_m | Planning buffer for uncertainty and conservative risk assessment |
