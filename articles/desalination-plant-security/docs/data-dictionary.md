# Data Dictionary

The file `data/raw/desalination_systems_synthetic.csv` contains synthetic demonstration data for desalination resilience analysis.

| Field | Description |
|---|---|
| city | Synthetic city or metropolitan area |
| region | Synthetic regional context |
| plant | Synthetic desalination plant name |
| served_population | Population served by the broader water system |
| priority_demand_mld | Priority water demand in million liters per day |
| normal_desal_output_mld | Normal desalination output in million liters per day |
| alternative_supply_mld | Alternative supply from groundwater, reservoirs, reuse, transfers, or other sources |
| storage_reserve_mld | Stored treated-water reserve measured as volume equivalent in million liters |
| emergency_transfer_mld | Emergency water transfer capacity in million liters per day |
| system_losses_mld | Distribution and system losses in million liters per day |
| outage_fraction | Fraction of desalination output lost during the scenario |
| backup_power_fraction | Fraction of plant operations supportable during power disruption |
| recovery_days | Estimated days required to restore normal output |
