# Ethics and Scope Note

Desalination plant security and water-infrastructure resilience affect public health, sanitation, urban stability, environmental protection, water affordability, and emergency governance.

This scaffold is limited to high-level resilience analysis using synthetic data. It does not provide offensive security guidance, facility-targeting information, exploit methods, or operational instructions for compromising infrastructure.

Applied use should involve qualified engineers, public utilities, emergency managers, cybersecurity professionals, environmental regulators, community stakeholders, and legally accountable institutions.
