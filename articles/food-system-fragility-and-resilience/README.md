**Food System Fragility and Resilience**

Article URL:

https://github.com/Content-Catalyst-LLC/risk-resilience-research/tree/main/articles/food-system-fragility-and-resilience

## Purpose

This folder provides reproducible scaffolding for modeling food system fragility and resilience as relationships among:

- production stress
- water stress
- ecological degradation
- logistics fragility
- input dependency
- price volatility
- household vulnerability
- inequality pressure
- social protection capacity
- nutritional adequacy
- food system diversity
- ecological buffer condition
- governance capacity
- market access reliability
- storage capacity
- trade dependency
- cross-sector linkage
- food system fragility
- food access vulnerability
- cascading food risk
- justice-weighted food risk
- food-resilience gaps
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced food system fragility diagnostics, scenario analysis, and Monte Carlo uncertainty
- R: dashboard-ready food system resilience, regional, type, and scenario summaries
- SQL: schema scaffold for food systems, indicators, price shocks, supply disruptions, and source provenance
- Go: lightweight food-risk scoring service scaffold
- Rust: command-line food-fragility scoring utility
- C: compact food-fragility calculation
- C++: justice-weighted food-risk example
- Fortran: numerical food-resilience gap example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
