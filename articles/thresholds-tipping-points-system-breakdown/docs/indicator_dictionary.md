# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| stress_load | Current level of accumulated stress or pressure | 0–1 |
| stress_rate | Rate at which stress is increasing | 0–1 |
| resilience_margin | Remaining operating space before critical boundary crossing | 0–1 |
| buffer_capacity | Ecological, infrastructural, institutional, or social buffer capacity | 0–1 |
| monitoring_capacity | Ability to detect weak signals and threshold approach | 0–1 |
| feedback_destabilization | Strength of destabilizing feedbacks relative to stabilizing feedbacks | 0–1 |
| threshold_proximity | Nearness to a critical behavioral boundary | 0–1 |
| interdependency_density | Degree of dependence among connected systems | 0–1 |
| cascade_exposure | Exposure of other systems to failure propagation | 0–1 |
| governance_readiness | Readiness to act under uncertainty before visible breakdown | 0–1 |
| recovery_capacity | Ability to recover after regime shift or service disruption | 0–1 |
| social_vulnerability | Susceptibility of affected communities to harm | 0–1 |
| justice_pressure | Degree to which breakdown risk is unevenly distributed | 0–1 |
| system_criticality | Importance of the system for essential services or cascading consequences | 0–1 |
| regime_shift_reversibility | Ability to return from an alternative state to the prior regime | 0–1 |
