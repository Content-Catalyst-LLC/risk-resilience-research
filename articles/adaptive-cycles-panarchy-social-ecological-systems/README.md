## Purpose

This folder provides reproducible scaffolding for modeling adaptive cycles and panarchy as relationships among:

- adaptive-cycle phase
- growth potential
- connectedness
- system rigidity
- resilience capacity
- release pressure
- reorganization capacity
- novelty potential
- memory capacity
- revolt pressure
- cross-scale dependency
- inequality pressure
- institutional learning
- ecological buffer condition
- governance flexibility
- transformation readiness
- resilience traps
- justice-weighted reorganization gaps
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced adaptive-cycle and panarchy diagnostics, scenario analysis, and Monte Carlo uncertainty
- R: dashboard-ready cycle, cross-scale, reorganization, and scenario summaries
- SQL: schema scaffold for systems, adaptive-cycle phases, cross-scale links, and scoring runs
- Go: lightweight panarchy-risk scoring service scaffold
- Rust: command-line adaptive-cycle scoring utility
- C: compact release-pressure calculation
- C++: cross-scale interaction example
- Fortran: numerical reorganization-gap example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
