# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| adaptive_phase | Current heuristic phase: r, K, Ω, or α | categorical |
| growth_potential | Capacity for expansion, experimentation, or resource accumulation | 0–1 |
| connectedness | Degree of structural connection among system parts | 0–1 |
| rigidity | Degree of lock-in, inflexibility, or conservation-phase brittleness | 0–1 |
| resilience_capacity | Ability to absorb disturbance while retaining identity and function | 0–1 |
| release_pressure | Pressure toward breakdown, collapse, or release of accumulated structure | 0–1 |
| reorganization_capacity | Ability to recombine resources after release | 0–1 |
| novelty_potential | Capacity for experimentation and emergence of new arrangements | 0–1 |
| memory_capacity | Retained ecological, institutional, cultural, and technical knowledge | 0–1 |
| revolt_pressure | Smaller/faster-cycle disturbance capable of affecting larger/slower systems | 0–1 |
| cross_scale_dependency | Degree of dependence among nested cycles and scales | 0–1 |
| inequality_pressure | Degree to which reorganization risks are unequal or unjust | 0–1 |
| institutional_learning | Ability of institutions to learn and adapt across phases | 0–1 |
| ecological_buffer_condition | Condition of ecological supports that enable renewal and resilience | 0–1 |
| governance_flexibility | Ability of governance to adapt without losing legitimacy | 0–1 |
| system_criticality | Importance of the system for essential functions and cross-scale effects | 0–1 |
