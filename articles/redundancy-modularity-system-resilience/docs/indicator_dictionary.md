# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| primary_failure_pressure | Current pressure that could trigger local failure | 0–1 |
| redundancy_capacity | Availability of alternate components, functions, or pathways | 0–1 |
| modularity_capacity | Ability to separate system parts and contain disruption | 0–1 |
| backup_diversity | Diversity of backup options, not only the number of backups | 0–1 |
| pathway_diversity | Availability of alternate routes, suppliers, or flows | 0–1 |
| spare_capacity | Reserve capacity available during disruption | 0–1 |
| coupling_intensity | Degree of tight coupling among system parts | 0–1 |
| dependency_concentration | Reliance on concentrated nodes, sources, or suppliers | 0–1 |
| containment_strength | Ability to keep local failure from spreading | 0–1 |
| restoration_capacity | Ability to restore function after disruption | 0–1 |
| monitoring_capacity | Ability to detect stress and observe failing components | 0–1 |
| governance_coordination | Ability to coordinate cross-sector action | 0–1 |
| social_vulnerability | Susceptibility of affected communities to harm | 0–1 |
| system_criticality | Importance of the system for essential functions | 0–1 |
| efficiency_pressure | Degree of pressure to remove slack in the name of efficiency | 0–1 |
