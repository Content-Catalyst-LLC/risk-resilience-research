## Purpose

This folder provides reproducible scaffolding for modeling cyber risk, digital dependency, and system resilience as relationships among:

- digital criticality
- threat pressure
- technical vulnerability exposure
- dependency concentration
- identity and access weakness
- vendor and software supply-chain exposure
- operational-technology exposure
- data-integrity risk
- recovery capacity
- governance capacity
- backup and redundancy capacity
- monitoring maturity
- logging maturity
- incident-exercise maturity
- user vulnerability
- digital dependency matrices
- cyber disruption pressure
- cyber resilience capacity
- systemic cyber risk
- cascading dependency exposure
- service-continuity gaps
- recovery-priority scoring
- scenario analysis
- uncertainty simulation

## Languages Included

- Python: advanced cyber dependency and system-resilience diagnostics
- R: dashboard-ready cyber resilience, sector, context, and scenario summaries
- SQL: schema scaffold for digital systems, dependencies, vendors, identity controls, vulnerabilities, incidents, recovery tests, and source provenance
- Go: lightweight systemic cyber-resilience scoring service scaffold
- Rust: command-line cyber-resilience capacity scoring utility
- C: compact systemic cyber-risk calculation
- C++: service-continuity gap and recovery-priority scoring example
- Fortran: numerical cyber service-continuity gap example

The examples use synthetic data and are intended for conceptual, educational, and research-scaffolding purposes.
