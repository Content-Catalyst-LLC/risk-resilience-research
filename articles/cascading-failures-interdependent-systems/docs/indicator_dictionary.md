# Indicator Dictionary

| Indicator | Meaning | Scale |
|---|---|---|
| initiating_shock_severity | Severity of the initial disruption | 0–1 |
| dependency_density | Degree of dependency among assets, sectors, services, and institutions | 0–1 |
| hidden_coupling | Degree of dependency not visible in formal diagrams or sector plans | 0–1 |
| critical_node_exposure | Exposure of critical nodes, chokepoints, or lifeline services | 0–1 |
| backup_capacity | Ability to continue function through backup systems | 0–1 |
| modularity_capacity | Ability to contain failure within modules or segments | 0–1 |
| cross_sector_coordination | Ability to coordinate across sectors and jurisdictions | 0–1 |
| restoration_speed | Expected speed of restoring essential supporting functions | 0–1 |
| redundancy_capacity | Availability of substitute pathways, suppliers, or service routes | 0–1 |
| social_vulnerability | Susceptibility of communities to harm from cascading disruption | 0–1 |
| governance_readiness | Institutional readiness to coordinate under cascading conditions | 0–1 |
| system_criticality | Importance of the system for essential functions and wider dependencies | 0–1 |
| cascade_exposure | Exposure of other systems to the initiating system’s disruption | 0–1 |
| monitoring_capacity | Ability to detect dependency stress and cascade onset | 0–1 |
| public_trust | Trust that supports coordinated action, compliance, and information uptake | 0–1 |
